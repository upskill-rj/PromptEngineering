
# Problem = Microservices Bootstrap (Spring Boot)


```pseudocode
BEGIN

    SERVICE UserService
        CONFIGURE port = 8081
        CONFIGURE serviceID = "user-service"
        CONFIGURE eurekaServer = "http://eureka:8761/eureka"

        ON STARTUP
            REGISTER self TO eurekaServer
            INITIALIZE databaseConnectionPool(minConn=5, maxConn=50)
            INTIALIZE redisCache(host="redis-cluster", ttl=3600)
            EXPOSE healthEndpoint("/actuator/health")
            EXPOSE metricsEndpoint("/actuator/metrics")
        END STARTUP
    END SERVICE

END
```
