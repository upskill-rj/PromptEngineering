# What is OpenTofu?

OpenTofu is an open-source **Infrastructure as Code (IaC)** tool created as a community-driven fork of Terraform.

It is managed by the Linux Foundation under the OpenTofu project.

---

# Why OpenTofu Was Created

OpenTofu emerged after HashiCorp changed Terraform licensing from open-source to Business Source License (BSL).

Goals of OpenTofu:

* Fully open-source
* Community-driven
* Terraform-compatible
* Vendor-neutral
* Enterprise-friendly

---

# Core Purpose

OpenTofu allows organizations to:

* Automate infrastructure provisioning
* Manage cloud infrastructure using code
* Support multi-cloud deployments
* Standardize infrastructure
* Enable DevOps and GitOps
* Provision AI/ML infrastructure

# Main Components of OpenTofu

---

# 1. OpenTofu Core

Main execution engine.

Responsibilities:

* Parse configuration files
* Create dependency graph
* Generate execution plan
* Maintain state
* Execute provisioning workflow

---

# 2. Providers

Providers connect OpenTofu to external platforms.

Examples:

* AWS
* Azure
* GCP
* OCI
* Kubernetes
* Docker
* GitHub

Example:

```hcl
provider "aws" {
  region = "ap-south-1"
}
```

---

# 3. Resources

Actual infrastructure objects.

Examples:

* EC2 instance
* Kubernetes cluster
* Database
* VPC
* Storage bucket

Example:

```hcl
resource "aws_instance" "app" {
  ami           = "ami-12345"
  instance_type = "t3.medium"
}
```

---

# 4. Variables

Reusable configuration inputs.

Example:

```hcl
variable "environment" {
  default = "dev"
}
```

Benefits:

* Environment separation
* Reusability
* Flexibility

---

# 5. Outputs

Return deployment information.

Example:

```hcl
output "server_ip" {
  value = aws_instance.app.public_ip
}
```

---

# 6. State File

Critical component.

Stores:

* Infrastructure metadata
* Resource IDs
* Dependency mappings
* Current infrastructure status

File:

```text
terraform.tfstate
```

OpenTofu maintains Terraform compatibility.

---

# 7. Modules

Reusable infrastructure templates.

Examples:

* VPC module
* EKS module
* AI platform module

Example:

```hcl
module "networking" {
  source = "./modules/vpc"
}
```

Enterprise benefits:

* Governance
* Standardization
* Faster provisioning

---

# 8. Backend

Remote state storage.

Examples:

* S3
* Azure Blob
* GCS
* OCI Object Storage

Example:

```hcl
terraform {
  backend "s3" {
    bucket = "infra-state"
    key    = "prod.tfstate"
    region = "ap-south-1"
  }
}
```

---

# 9. Data Sources

Read existing infrastructure.

Example:

```hcl
data "aws_vpc" "default" {
  default = true
}
```

Useful for:

* Hybrid cloud
* Existing enterprise environments

# Step-by-Step Process

---

## 1. Write Configuration

```hcl
resource "aws_s3_bucket" "logs" {
  bucket = "enterprise-log-bucket"
}
```

---

## 2. Initialize

```bash
tofu init
```

Downloads:

* Providers
* Modules
* Plugins

---

## 3. Validate

```bash
tofu validate
```

Checks configuration syntax.

---

## 4. Plan

```bash
tofu plan
```

Preview infrastructure changes.

---

## 5. Apply

```bash
tofu apply
```

Provision infrastructure.

---

## 6. Destroy

```bash
tofu destroy
```

Delete infrastructure.
