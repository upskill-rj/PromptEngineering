# PMP Overview

## What is PMP?

PMP stands for **Project Management Professional**, a globally recognized certification offered by the Project Management Institute.

PMP validates:

* Project management knowledge
* Leadership skills
* Agile and predictive methodologies
* Risk and stakeholder management
* Enterprise delivery capability

It is widely used in:

* IT
* Banking
* Healthcare
* Construction
* Telecom
* Cloud and AI projects

# PMP Process Groups

PMP is divided into 5 major process groups.

| Process Group            | Purpose               |
| ------------------------ | --------------------- |
| Initiating               | Start the project     |
| Planning                 | Define roadmap        |
| Executing                | Build and deliver     |
| Monitoring & Controlling | Track and optimize    |
| Closing                  | Finalize and handover |

---

# 1. Initiating Process Group

## Purpose

Defines project goals and stakeholders.

## Components

* Business case
* Project charter
* Stakeholder identification

## Example

Starting a banking mobile application project.

## Deliverables

* Project Charter
* Stakeholder Register

# PMP Methodology Types

# 1. Predictive (Waterfall)

Traditional sequential project management.

## Characteristics

* Fixed requirements
* Structured phases
* Heavy documentation

## Use Cases

* Government systems
* Construction
* Infrastructure projects

---

# 2. Agile PMP

Iterative and flexible approach.

## Components

* Sprint
* Product backlog
* User stories
* Continuous feedback

## Use Cases

* SaaS platforms
* AI systems
* Cloud-native applications

---

# 3. Hybrid PMP

Combination of Waterfall + Agile.

## Example

* Infrastructure using Waterfall
* Application using Agile

## Use Cases

* Enterprise digital transformation
* Banking modernization

# PMP Interview Questions & Answers

## Q1. What is PMP?

PMP is a globally recognized project management certification from PMI that validates project leadership and delivery skills.

---

## Q2. What are PMP process groups?

| Group      | Purpose           |
| ---------- | ----------------- |
| Initiating | Start project     |
| Planning   | Define roadmap    |
| Executing  | Build solution    |
| Monitoring | Track performance |
| Closing    | Complete project  |

---

## Q3. What is WBS?

Work Breakdown Structure divides project work into smaller manageable tasks.

---

## Q4. Difference between Agile and Predictive PMP?

| Agile               | Predictive           |
| ------------------- | -------------------- |
| Iterative           | Sequential           |
| Flexible            | Fixed scope          |
| Continuous feedback | Defined requirements |
| Faster adaptation   | Structured planning  |

---

## Q5. What is risk management in PMP?

Risk management identifies, analyzes, mitigates, and monitors threats impacting project delivery.

# Short Interview Summary

“PMP is a globally recognized project management framework and certification from PMI. It includes process groups like Initiating, Planning, Executing, Monitoring, and Closing, along with knowledge areas such as scope, risk, cost, quality, communication, and stakeholder management. PMP supports predictive, Agile, and hybrid delivery models for enterprise-scale cloud, AI, DevOps, and microservices projects.”
