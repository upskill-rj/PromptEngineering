ODI (Oracle Data Integrator) = It is an ETL as well as ELT tool and have many uses.

- Mainly used to extract data from a certain sources.
- Sources could be files / databases.
- Transform data in a staging area and then loads the data into target Source (database / files).
- Transformations take place on the target database using SQL
- It offers transparency (developer can see what is exactly going on, which is helpful for debugging)
- Code template approach enables reusability.
- Data transformation logic and strategies are captured in Knowledge Modules , which can be re-used across the database.
- It could be used in several type of projects.

e.g.; i) Conventional Data Integration
ii) Business Intelligence and Data Warehousing
iii) Modernization Initiatives
iv) Migrations and Consolidations
v) Service Oriented Architecture Initiatives
vi) Master Data Management
