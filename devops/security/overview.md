* The Suricata engine is capable of real time intrusion detection (IDS), inline intrusion prevention (IPS), network security monitoring (NSM) and offline pcap processing.

# Security Implications of GET/POST Interchangeability

In Java EE, the problem is generally more prevalent than in PHP, as Java does not provide separate functions to access GET and POST data. The only function providing this data is getParameter of ServletRequest.

Thus, a developer has to explicitly check the HTTP method via the getMethod function. The used framework may also provide specific methods to retrieve only GET or POST, or may provide a routing functionality regulating which requests are allowed and which are not.



* GET ====   The GET request is supposed to be for requesting a certain resource. In other words, the user is asking the server for a certain image or file to be downloaded.

* POST ==== The POST request is supposed to be used for submitting data to be processed. The data that the user is posting is in the body of the request and may actually make a new resource. POST requests should always be used when transporting sensitive data, since these requests are not cached. However, if confidentiality of the data is needed, SSL must be used to encrypt the traffic in transit.
