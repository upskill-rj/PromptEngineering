# Mandatory Skills

• Design and build high-performance services using modern Java, clean code, and strong OO/FP principles.
• Spring Boot: Architect Spring Boot applications with standard conventions, configuration management, and production readiness.
• REST APIs: Define REST contracts, versioning, error models, pagination, idempotency, and backward compatibility standards.
• Microservices: Design microservices with domain boundaries, service decomposition, and clear ownership aligned to business domains.
• ORM (JPA/Hibernate): Model entities and persistence with correct mappings, transactions, fetch strategies, and performance tuning.
• BFF pattern: Design Backend-for-Frontend services tailored for mobile/web needs to optimize payloads, latency, and UX flows.
• OAuth2/OIDC: Implement secure auth flows, token lifecycle, scopes, and integration with Identity Providers.
• Identity Providers: Integrate with IdPs (Azure AD/Okta/Cognito/Keycloak) for SSO, federation, and centralized policy control.
• Security by design: Apply OWASP principles, secure defaults, input validation, threat modeling, and secure secret management.
• API optimization for mobile: Reduce chattiness via batching, caching, compression, and field selection; design for low bandwidth.
• Resilience patterns: Implement timeouts, retries, backoff, circuit breakers, bulkheads, and graceful degradation.
• Observability: Standardize logs, metrics, tracing, correlation IDs, and dashboards to reduce MTTR and improve reliability.
• Performance engineering: Profile JVM, tune GC, optimize DB queries, and eliminate hotspots under real production load.

• Mocking: Use Mockito/WireMock/Testcontainers to isolate dependencies and run reliable CI-friendly integration tests.
• Best practices: Enforce coding standards, code reviews, static analysis, and secure dependency management.
• Cloud architecture: Design cloud-native services on AWS/Azure/GCP including networking, storage, IAM, APIM, and scaling patterns.
• Hands-on experience with containerisation and orchestration using Docker and Kubernetes, on managed platforms such as EKS/AKS/GKE.
• CI/CD: Build pipelines for build/test/scan/deploy with quality gates, artifact versioning, and automated rollbacks.
• Git workflow: Apply Git best practices, and enforce PR hygiene and branching discipline.
• Agile delivery: Participate in refinement/planning; translate NFRs into stories; align design to iterative delivery.
• Documentation/ADRs: Produce architecture docs, ADRs, and runbooks capturing decisions, trade-offs, and ops readiness.
