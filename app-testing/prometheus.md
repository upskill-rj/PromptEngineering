# Prometheus Overview

Prometheus is an open-source monitoring and alerting system used to collect, store, and analyze time-series metrics from applications, servers, Kubernetes, cloud infrastructure, and AI systems.
It is widely used in cloud-native, microservices, DevOps, MLOps, and AI/LLM environments.

### Interview Definition (2-3 Lines)

“Prometheus is a metrics-based monitoring platform that collects real-time telemetry data from applications and infrastructure using a pull-based model. It is commonly used with Kubernetes, Grafana, and AI systems for monitoring latency, errors, GPU usage, and application health.”

# Core Components of Prometheus

# 1. Prometheus Server

The main component that:

* Scrapes metrics
* Stores time-series data
* Executes queries
* Triggers alerts

### Example

Prometheus server collects:

* CPU metrics from servers
* AI latency metrics from APIs
* Kubernetes pod health

---

# 2. Metrics

Metrics are numerical measurements collected over time.

### Common Metrics

* CPU usage
* Memory utilization
* Request count
* API latency
* GPU temperature

### AI Example

AI application metrics:

* LLM response time = 5 sec
* Token usage = 15K/min
* Vector search latency = 300ms

---

# 3. Time-Series Database (TSDB)

Prometheus stores data as time-series:

```text id="jb6r1h"
metric_name + timestamp + value
```

### Example

```text id="b1k5wp"
gpu_usage{server="gpu-node1"} = 92%
```

### AI Example

Track GPU utilization trends during AI model inference.

---

# 4. Exporters

Exporters expose metrics from external systems in Prometheus format.

### Popular Exporters

| Exporter            | Purpose             |
| ------------------- | ------------------- |
| Node Exporter       | Server metrics      |
| cAdvisor            | Container metrics   |
| kube-state-metrics  | Kubernetes metrics  |
| NVIDIA GPU Exporter | GPU monitoring      |
| Blackbox Exporter   | Endpoint monitoring |

### AI Example

NVIDIA exporter collects:

* GPU memory usage
* CUDA utilization
* Temperature

for AI training workloads.

---

# 5. Scraping

Prometheus periodically pulls metrics from targets.

### Flow

```text id="18blxr"
Prometheus → Target Endpoint → Collect Metrics
```

### Example

Prometheus scrapes:

```text id="g0jlwm"
http://app:9090/metrics
```

every 15 seconds.

### AI Example

Collect:

* LLM latency
* Token count
* AI request failures

from AI microservices.

---

# 6. Targets

Targets are systems from which Prometheus collects metrics.

### Examples

* Servers
* Kubernetes pods
* APIs
* Databases
* AI applications

### AI Example

Targets:

* Vector DB
* Model-serving API
* GPU node
* Embedding service

---

# 7. PromQL (Prometheus Query Language)

PromQL is used to query and analyze metrics.

### Example

```text id="0m7rhb"
rate(http_requests_total[5m])
```

Calculates request rate over 5 minutes.

### AI Example

Query:

```text id="gh8yzy"
avg(ai_inference_latency)
```

Find average AI response time.

---
